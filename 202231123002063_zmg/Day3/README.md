本项目实现了一个基于 PyTorch 的图像分类流程，包含数据预处理、模型训练和验证功能。项目结构清晰，便于扩展和修改。

项目结构
text
.
├── dataset.py            # 数据集加载和处理
├── deal_with_datasets.py # 原始数据集划分工具
├── prepare.py           # 生成训练/验证集文本文件
├── model.py             # 模型定义
├── train.py             # 主训练脚本
└── README.md            # 项目说明文档
功能说明
数据准备

自动划分原始数据集为训练集和验证集

生成包含图片路径和标签的文本文件

模型训练

使用 ResNet18 作为基础模型

支持自定义分类类别数量

包含训练和验证过程监控

数据增强

标准化图像大小 (224x224)

应用常见的图像增强技术
